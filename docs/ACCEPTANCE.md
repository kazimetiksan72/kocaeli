# Sürüm 1 kabul senaryosu

1. `admin` ile mock giriş yap.
2. Talepler ekranında mahalle ve harita noktası içeren, fotoğraf metadata kaydı bulunan talep oluştur.
3. Benzer kayıtlar panelinde yakın/benzer talepleri doğrula.
4. Talebi İzmit birimine ve `teknik.izmit` kullanıcısına ata.
5. Teknik kullanıcıyla keşif oluştur, teknik açıklama/sonuç/fotoğraf ekle ve tamamla.
6. Yönetici onayına gönder; `mudur.izmit` ile onayla.
7. Proje adayı veya faaliyet dönüşümünü çalıştır.
8. Dashboard, harita, bildirim ve audit ekranlarında kaydı doğrula.
9. `teknik.gebze` ile aynı API kaydının 403/404 ile korunmasını doğrula.
